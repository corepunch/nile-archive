# Resource panels review

Before and after captures of the shared resource panel (`skin:draw_resource`, see
[UI_ENGINE.md](../../UI_ENGINE.md#skins)) in each game's HUD, and of the Relic Rush
puzzle screen without its jade bands. Files are `<game>-<screen>-before.jpg` and
`-after.jpg`: `rr` is Relic Rush, `cm` Christmas Market, `na` Nile Archive and `em`
Emergency.
