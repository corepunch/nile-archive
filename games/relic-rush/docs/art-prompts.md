# Organic island background

Created with the built-in image generation tool, then integrated into the SDL runtime. Source: `art/island-organic.jpg`; runtime texture: `data/island.jpg`, built by `tools/prepare_assets.py`.

Prompt brief: a naturally shaped tropical archaeological expedition island with one large contiguous grassy interior for interactive building placement; premium detailed isometric hand-painted mobile island-garden art, warm lighting, an asymmetric sandy/rocky shoreline, turquoise lagoon, peripheral palms, flowers, tiny ancient stones, one narrow meandering footpath and a small jetty. Keep the central 70% largely open. Avoid buildings, fixed plots, terraces, symmetrical clearings, a central dividing river, UI, grid, text and characters. Original 1024×1536 portrait artwork. The game renders it as a world map, with separate interactive buildings and region fog.

Screenshots in docs are rendered by the real SDL game. `island-village.png` is a presentation save with an example custom layout; `island-placement.png` shows a real movable preview, `island-zones.png` the region overview, and `hex-first.png` / `hex-late.png` actual redesigned levels.
