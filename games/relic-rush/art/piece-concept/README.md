# Relic Rush piece concept

Exploratory artwork for six original, mostly single-colour match-3 pieces:
sun, scarab, water drop, leaf, purple relic and flame. This is a single
transparent 3×2 ImageGen atlas, generated together on 2026-11-12 with the
built-in image generator. It is a visual proposal, not registered runtime art;
the alpha and spacing need review at board size before production use.

Prompt:

> Create one coherent set of six original collectible game pieces in a precise
> 3 columns by 2 rows grid, each centered in its own equally sized cell, with
> generous empty space between objects, on a genuinely transparent background.
> Top row: warm yellow sun stone, saturated red rounded carved scarab, bright
> blue water-drop gemstone. Bottom row: saturated green rounded leaf stone,
> vibrant purple faceted relic, orange rounded clay flame relic. Distinct, bold
> easily readable silhouettes, each object almost entirely one dominant color,
> big exaggerated chunky forms, soft bevels, juicy glossy highlights and gentle
> ambient shading, polished friendly casual mobile puzzle game artwork. Each
> occupies the same apparent size, viewed straight on, no bases, no framing
> tiles, no letters, no numbers, no labels, no outlines around cells, no shadows
> outside the objects. Original designs, do not copy any existing game objects.
> Six separate complete objects only.
