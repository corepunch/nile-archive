# Enlarged painted sprites

The registered Blender renders at `ef26de3` are the geometry guides for the new `z-enlarged` ImageGen atlas. The source, exact prompt, layout, style reference and import transforms are recorded under `art/building-catalogue/painted-v1/`. Normal sprites are authored artwork; the game uses the separately rendered shadows.
